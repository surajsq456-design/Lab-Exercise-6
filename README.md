## AIM

To generate low-fidelity UX solutions using ideation techniques, create user stories and contextual scenarios, design user flows, and develop an information architecture for a digital application.

## ALGORITHM / PROCEDURE

1. Select a known UX problem.
2. Conduct a Crazy 8s or brainwriting ideation exercise.
3. Generate multiple low-fidelity solution ideas.
4. Select a suitable solution.
5. Create at least five user stories based on user goals.
6. Select one user story and develop a contextual scenario.
7. Identify the user's emotions, tasks, and environment.
8. Create a task flow diagram for the selected task.
9. Identify major sections and categories of the application.
10. Perform card sorting and create a site map.
11. Analyze the overall flow and information structure.
    
## OUTPUT
## 1. SOLUTION IDEATION
## UX PROJECT SCENARIO – HOSPITAL APPOINTMENT APP
## Problem:
Patients find it difficult to search for doctors, check availability, and book hospital appointments quickly.

## Crazy 8s / Brainwriting Ideas
1. Search doctors by specialization.
2. Show available appointment slots directly.
3. Select a preferred date and time.
4. Provide doctor profiles with specialization and experience.
5. Send appointment reminders.
6. Allow patients to reschedule or cancel appointments.
7. Provide digital appointment confirmation.
8. Show upcoming appointments on the home screen.
   
## Selected Solution
## Smart Doctor Appointment Booking System

The app allows users to search for doctors, view available time slots, book appointments, receive reminders, and manage upcoming appointments.

## 2. CREATING USER STORIES

1. As a patient, I want to search for doctors by specialization, so that I can find the right doctor easily.

2. As a patient, I want to view available appointment slots, so that I can choose a convenient time.

3. As a patient, I want to book an appointment online, so that I do not have to wait at the hospital.

4. As a patient, I want to receive appointment reminders, so that I do not miss my appointment.

5. As a patient, I want to reschedule or cancel an appointment, so that I can manage changes in my schedule.
   
## 3. CREATING SCENARIOS
Selected User Story
As a patient, I want to book an appointment online, so that I do not have to wait at the hospital.

## Narrative Scenario

Meena is a working professional who needs to consult a doctor for a routine health problem. She has limited free time and does not want to visit the hospital just to wait for an appointment.

She opens the hospital appointment app and searches for a suitable doctor. She checks the doctor's specialization and available time slots. After selecting a convenient slot, she confirms the appointment.

She feels relieved and satisfied because she can book the appointment quickly without waiting in a hospital queue.

## User Environment

* Uses a smartphone.
* May book the appointment from home or workplace.
* Has limited time.
* Requires simple and quick navigation.
* Uses mobile internet.
  
## Emotional State
* Before: Worried / Frustrated
* During: Focused / Confident
* After: Relieved / Satisfied
